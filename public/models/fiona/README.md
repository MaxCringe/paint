# Fiona 3D — KNOTTY PINE

Эта папка предназначена для новой 3D-модели Фионы со скелетом.

## Что загрузить
- Основную модель со скелетом: `Fiona.fbx` (переименуй твой rigged-model FBX перед загрузкой).
- Необязательно: текстуры модели, если они идут отдельными файлами.

Анимации Mixamo впоследствии разместим отдельно в `public/models/fiona/animations/`, когда выберем подходящие версии.

**Важно:** текущий режим «ТЕСТ НОВОЙ ФИОНЫ · DEV» ещё использует выбор локальных файлов в браузере. Одна только загрузка модели в GitHub пока не подключает её автоматически к игре. После загрузки FBX настроим автозагрузку и проверим анимации.

Не удалять существующего процедурного персонажа и не заменять его без тестирования.
