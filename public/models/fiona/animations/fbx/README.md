# FBX-анимации Фионы — KNOTTY PINE

Загружай сюда отдельные файлы **`.fbx`** с анимациями для скелета новой Фионы. Это папка для исходников анимаций (например, скачанных с Mixamo).

## Как загрузить
1. Открой эту папку на GitHub.
2. Выбери **Add file → Upload files**.
3. Перетащи все нужные файлы `.fbx` и нажми **Commit changes** в ветку `main`.

Рекомендуется выбирать на Mixamo экспорт **FBX Binary, Without Skin** (если модель Фионы уже имеет скелет). Не обязательно переименовывать файлы перед загрузкой, но понятные названия облегчат подключение: `Run.fbx`, `Idle.fbx`, `Jump.fbx`, `DoubleJump.fbx`, `Slide.fbx`, `MoveLeft.fbx`, `MoveRight.fbx`, `Land.fbx`, `BroomFly.fbx`, `Death.fbx` и т. д.

Файл `Flying.fbx` был отклонён и удалён из актуальной версии по просьбе пользователя; новую анимацию полёта можно будет загрузить сюда позднее.

Существующие сгенерированные Python-анимации `../motions.json.gz` и `../run-calibrated.json.gz` не трогать. **Загрузка файлов в эту папку не подключает их автоматически к игре.** Сначала нужно проверить соответствие костей и добавить загрузчик/ретаргетинг в DEV-тест Фионы, сохранив обычный забег без изменений.
