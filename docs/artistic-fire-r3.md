# Эффекты мира r3

Архив Google AI Studio в этой сессии отсутствовал. Сравнение ниже относится к
описанию пользователя и исходникам игры на `78f88a9`; исходные файлы архива не
проверены и не скопированы. Алгоритмы новой реализации написаны независимо.

| Приём из описания исходника | Игра до изменения | Реализация r3 |
| --- | --- | --- |
| Раздвоение, внешняя оболочка | Один низкополигональный язык | Пять параметрических силуэтов, две оболочки, независимые фазы и шум |
| Объёмные клубы | Мягкие PlaneGeometry | IcosahedronGeometry с шумом/мягким краем; лёгкие карты и LOD сохранены |
| Поверхностные 3D-угли | Только летающие embers | Отдельный слой coals с неподвижной геометрией и мерцанием |
| Художественный цикл дерева | Постоянное горение | Низ → середина → крона → тление, ручной/автоматический/постоянный режим |

## Работа

Открыть настройки → «Редактор мира» в dev или сборке
`VITE_ENABLE_WORLD_EDITOR=true`. Также поддерживается `?worldEditor=1&seed=1337`.
Публичная сборка без флага скрывает авторский интерфейс. Галерея — SVG,
дополнительных WebGLRenderer нет.

1. «Добавить огонь / дым / искры / тление» выбирает состав и включает размещение.
2. Карточка выбирает композицию. Выбранный существующий очаг можно заменить карточкой.
3. Щелчок по поверхности размещает эффект. «Ствол» и «Крона» на дереве создают
   несколько нерегулярных очагов в реальных точках профиля соответствующего вида.
4. Форма пламени изменяет геометрию; источник задаёт область эмиссии независимо.
   Более сложные параметры формы и дыма находятся в дополнительных настройках.

Слой coals — неподвижные тлеющие участки, embers — летящие угольки,
sparks — искры. Дым не требует пламени, подсветка снизу отключена по умолчанию.
Стадии управляют очагами выбранного дерева; не распространяются между деревьями.
По умолчанию остаётся постоянное горение.

JSON v3 сохраняет формы, качество дыма, угли и цикл. Импорт v1/v2 сохраняет
трансформации и параметры: старое пламя получает форму legacy, дым — light,
цикл — constant. Слои, Undo/Redo, именованные пресеты и явные массовые действия
сохранены. Общий runtime используется в редакторе и обычном забеге.

## Воспроизводимая проверка

`effects-comparison.html` включён только в редакторскую сборку: фиксированный seed
1337, время 1.25, передний/боковой/верхний ракурс, игровой/рабочий свет.
Пять форм имеют одинаковые цвет, высоту, ширину, плотность и фазу.
Силуэты получены из WebGL-пикселей, каждый нормализован к своему bounding box:
попарный IoU 0.20–0.66. Это проверяет изменение силуэта независимо от размера,
цвета и времени. Композиции показывают костёр, пожар, отдельный дым и тление;
три дерева показывают стадии .20/.55/.95. Один renderer на всю сцену.

`tests/artistic-fire.test.js` проверяет миграцию, две оболочки, стадии, паузу,
поверхностные угли, LOD и воспроизводимое размещение. Браузерный тест сохраняет
девять ракурсов, проверяет настоящие силуэты, прямое размещение дыма,
настройку стадий, JSON и повторное открытие. Старые тесты редактора проверяют
манипуляторы, историю и эффекты в обычном забеге.

Бюджет общий для всех пяти пакетов: огонь, дымовые карты, объёмный дым,
поверхностные угли, летающие частицы. Нет источника света на каждый очаг.
Объёмный дым ограничен 512 экземплярами и становится картами вдали.

## Как отличить сборку

Заголовок редактора и сравнительной сцены показывает r3 и Git SHA.
`editor-build.json` содержит полный SHA, время и editorEnabled. Старая immutable
Vercel-ссылка не становится новой от push в main. По аудиту пользователя адрес
`paint-4oxamzjy7-appleiiddd-7348.vercel.app` относится к `0d32be8`.
Повторное чтение этой ссылки в среде блокируется прокси (CONNECT 403).
Без Vercel credentials новая публикация из этой среды невозможна; локальная
сборка и GitHub-коммит сами по себе не доказывают публикацию.

## Результат измерения производительности

Chromium/system SwiftShader, 1280×720, seed 1337, одинаковый v2-пресет из трёх
inferno-источников, бюджет 1024, одна камера обычной игровой сцены; отдельный
процесс браузера на сборку. После 20 кадров прогрева измерены ещё 20 кадров.

| Сборка | Медиана, мс | p95, мс | Вызовов отрисовки |
| --- | ---: | ---: | ---: |
| 78f88a9 | 816.6 | 933.4 | 98 |
| r3, отключённые оболочки не рисуются | 783.4 | 1500.0 | 98 |

Медиана не ухудшилась; хвост времени кадра на программном GPU нестабилен и
ухудшился в этом замере. Это не подтверждает неизменность FPS на настоящей
видеокарте/мобильном устройстве. Дополнительные объёмные слои требуют своего
бюджета; отключённые пакеты скрываются, внешняя оболочка при opacity=0 исключена
из drawRange. Обычный забег без сохранённого авторского пресета использует
прежний путь, редакторский runtime не создаётся.

Проверки: `npm test` — успешно; Vite с флагом true и false — успешно
(сохраняется предупреждение о размере основного чанка). Браузерные сценарии
редактора — 4 существующих и 2 новых; публичная сборка — 5 успешных сценариев,
редакторские сценарии в ней ожидаемо пропущены. WebGL shader/page errors при
сравнении отсутствуют. Проверены импорт v2, экспорт/импорт v3 и повторное
открытие редактора. Архив исходного демоприложения и настоящая видеокарта
в среде отсутствуют. Vercel deploy/login не выполнен: нет credentials,
временная публикация отклонена сервисом, сетевой вход возвращает fetch failed.
