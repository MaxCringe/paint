# Атмосфера Fire Studio

Откройте редактор мира и верхнюю вкладку **Атмосфера**. Пресеты «Текущая атмосфера»,
«Туманный адский лес» и «Пепельная буря» можно менять ползунками или точными числами.
Дополнительные параметры доступны в расширенном режиме и сворачиваемых разделах.
«Скрыть туман» — временное сравнение, которое не меняет сохранённый пресет.

Настройки автоматически сохраняются в поле `atmosphere` (с собственной `version: 1`)
существующего `knottyPine.worldFire.v1`. Старые JSON без этого поля остаются валидными.
Общий JSON редактора включает атмосферу, отдельные кнопки вкладки обмениваются только
атмосферой (`format: knottyPine.atmosphere`). Undo/Redo общий с огнём. Закрытие редактора
возвращает выбранную атмосферу в игру; временное скрытие тумана снимается.

Используются существующие Points-пулы AirLite и вулкана, WindSystem и малошаговая
дымка AirLite. Новых проходов постобработки нет. Уровень качества ограничивает
фактический draw range пепла и вулканических частиц и число видимых слоёв дымки.
Диагностика показывает активные частицы, верхнюю оценку draw calls атмосферы
и время CPU-обновления (включая ветер). Это не измерение времени GPU и не гарантия FPS.
Густота ограничена, ближняя игровая дорога исключена из граничных слоёв дымки.
Горы плавно смешиваются с цветом тумана без изменения геометрии.

«Дальность начала тумана» оставляет ближнюю зону прозрачной. «Дальность полного
скрытия» задаёт базовый конец перехода. Глубина и плотность дальнего слоя усиливают
поглощение и приближают этот конец, оставляя минимум 30 единиц для мягкого перехода
после начала. Влияние на деревья дополнительно регулирует расстояние затухания;
влияние на горы задаёт растворение фона, которое усиливается с оптической глубиной.
«Мягкость перехода» меняет кривую смешивания фона и существующую локальную дымку.
Цвет неба согласуется с дальним туманом, чтобы затуманенные горы не образовывали
контрастный силуэт; временное скрытие тумана возвращает исходный цвет неба.
Обновлённый пресет «Туманный адский лес» почти полностью скрывает горы; старые
пользовательские значения не перезаписываются — выберите пресет заново для обновления.

Следующий этап: художественная настройка по референсам, проверка на реальных
мобильных GPU. Декоративные метеоры и частицы способностей остаются в своих системах;
вкладка не меняет их и не управляет огнём Fire Studio.
