# Генерация забега и темп

`RunSpace.js` задаёт абсолютную координату `s` в мировых единицах.
Пройденный путь `runPath` не циклируется; HUD показывает `runPath * .72`.
Положение объекта: `z = 2.3 + runPath - s`. Визуальные фабрики не планируют путь.

`RUN_DIRECTOR_CONFIG` в `src/systems/RunDirector.js` содержит данные для будущего
редактора: версию, длительности четырёх фаз **в мировых единицах**, плотность,
веса комбинаций и типов, награды, интервалы, горизонт и бюджет проверки.
Цикл: warmup → build → tension → recovery; скорость при смене фаз не сбрасывается.
Параметры распознавания — начальная настройка баланса, требующая проверки на телефонах.

Генератор сначала проверяет интервалы и резервации соседних секций, затем ищет
свидетельство проходимости: последовательность настоящих команд с симуляцией
`DoubleJump`, `Slide`, движения между полосами и существующих защит полёта.
Известные будущие метлы учитываются. Проверка использует текущее состояние Фионы;
каждый новый кандидат проверяется также при шагах 1/30 и .04 секунды.
Поиск ограничен: не более 12 маршрутов, 2400 шагов на маршрут и 6000 шагов суммарно на одну проверку. Неподтверждённая
комбинация заменяется пустой восстановительной секцией без повторной генерации.
Это консервативный поиск: допустимую сложную комбинацию он может отклонить.

Награды размещаются на проверенном выходном маршруте. Между наградой и следующей
опасностью резервируется время распознавания и манёвра. Платок использует общий
реестр; неудачное предложение повторяется, накопленный инвентарь не меняется.

Проверки: `npm test`, `npm run build`. Для интеграционного прохождения полного
цикла: `npm run build -- --mode test`, затем `RUN_DIRECTOR_TESTS=1 npm run test:browser -- tests/browser/run-director.spec.js --grep "initial sections"`.
Полное игровое прохождение цикла: тот же вызов с `--grep "extended:"`;
из-за стоимости software WebGL оно допускает до 20 минут.
Только эта тестовая сборка предоставляет `window.__knottyRunTest` для снимка
состояния и настоящих команд; в production ветка удаляется Vite. В тесте нет
пропуска коллизий, изменения скорости или выдачи защиты.
