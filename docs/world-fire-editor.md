# Редактор огня в игровой сцене

## Открытие

Локально: `npm run dev`, затем **Настройки → Инструменты разработчика → Редактор мира**.
В dev-среде редактор доступен по умолчанию; `VITE_ENABLE_WORLD_EDITOR=false`
явно отключает раздел. Закрытие возвращает на ту же страницу настроек,
сохраняя аудиопараметры и состояние паузы. Редактор загружается при первом нажатии,
последующие открытия используют тот же экземпляр.
Прямой адрес `?worldEditor=1&seed=1337` по-прежнему поддерживается.
В production без `VITE_ENABLE_WORLD_EDITOR=true` ни раздел, ни редактор не создаются.
Для специальной сборки: `VITE_ENABLE_WORLD_EDITOR=true npm run build`, затем тот же query-параметр.
Обычная production-сборка (`npm run build`) исключает модуль редактора.
Это переключатель рабочего режима, а не механизм авторизации.

Редактор использует настоящую сцену и реальные instanced-модели леса. Забег,
ветер, переработка растений, препятствия и камера игры останавливаются;
редакторская камера и огонь продолжают обновляться. Для удобства добавлены
временное рабочее освещение и настоящая лавовая переправа, не зарегистрированная
в списке игровых препятствий. После закрытия возвращаются исходные свет и туман,
игровая камера, состояние забега и ввод. Демонстрационная переправа убирается.

## Актуальная работа с эффектами

Редактор расширен до многослойной версии: пламя, дым, искры и угольки,
11 пресетов, числовые поля, формы источников, локальные/массовые действия,
именованные пресеты, seed-распределение и формат JSON v2 с миграцией v1.
Подробное руководство и проверенные API: [Многослойные эффекты мира](world-effects.md).

В обычном режиме правки теперь принадлежат выбранному объекту. Массовое
применение выполняется только отдельными кнопками. Сохранённые настройки
загружаются также в обычном забеге, даже когда редакторский UI исключён из сборки.

`ForestGenerator` остаётся владельцем instanceMatrix. `resolveInstance(mesh,
instanceId)` возвращает корневой прокси, plantId, species и template. Следующий
этап кистей растений должен записывать версионированные слои размещения
(family/species, seed, область, плотность, scaleRange, параметры групп) и
пересоздавать прокси/батчи через генератор. Постоянное редактирование instanceMatrix
не является источником авторских данных.

- Исходная точка: `226cbdc392d9b5306590c1bac97ef5e810233450`.
- 141 unit-тест прошёл; полный браузерный набор — 5/5. Отдельно повторён
  редакторский сценарий с настоящим перетаскиванием стрелки, Undo/Redo этого
  перетаскивания и повторным открытием/закрытием из паузы — успешно.
- Сборки с редактором и без него проходят. Обычная сборка не содержит chunk
  WorldEditor. Обычные игровые сценарии проверены с Chromium и software WebGL.
- Сравнение неизменённого main и новой версии: одинаковый непрерывный seeded
  случайный поток в отдельном измерительном скрипте, viewport 1280×720, 40 кадров
  стабильной сцены. Обе версии: 96 draw calls/кадр, без UI и загрузки редактора.
  Медиана кадра 1249.9 → 1233.2 мс; p95 3383.2 → 2616.6 мс. Программный WebGL
  в облаке очень медленный; эти числа показывают отсутствие регрессии в данном
  сравнении и не прогнозируют FPS на устройстве игрока.
- Снимок редактора сохраняется браузерным тестом в `world-editor.png` в его
  каталоге результатов. В старом Fire Studio smoke-тесте автоматический запрос
  Chromium к отсутствующей favicon изолирован отдельным ответом; проверка
  ошибок shader/WebGL сохранена.

### Публикация отдельного Preview

С существующей Vercel-авторизацией: `vercel deploy --environment preview
--build-env VITE_ENABLE_WORLD_EDITOR=true`. Флаг передаётся только этой сборке;
не добавляйте его со значением true в Production-настройки проекта.
После публикации: главная страница Preview → Настройки → Редактор мира;
для прямого входа можно добавить `?worldEditor=1&seed=1337`.
Для Vercel CLI нужен доступ к проекту через сохранённый вход или VERCEL_TOKEN.
Секреты не хранить в репозитории.
