# Fire Studio 2.0: аудит предоставленного архива

Источник: `knotty-pine-—-fire-studio.zip`, предоставлен владельцем. Проверена версия
файлов от 2026-11-02. Основа игры перед интеграцией — `6e0e53b` (включает безопасный
сброс эффектов из параллельных коммитов). Предыдущий r3 создавался без архива;
сейчас есть прямое сравнение исходного кода.

## Инвентаризация

- `types.ts`: FireSettings (mode, quality, seed и 12 визуальных параметров),
  локальные semantic anchors, instanced binding, бюджеты, палитра, burn state, telemetry.
- `math.ts`: Mulberry32, clamp/smoothstep/lerp, три quality budget, температурная
  палитра, 4 стадии горения, вес якоря, нормализация JSON. Три MODE_PRESETS:
  tree, lava, smoldering. Других готовых пресетов в архиве нет.
- `geometry.ts`: кэш органических языков (7×10 / 10×14 / 14×20; low — одна оболочка,
  medium/high — две), Icosahedron дыма, сплющенный Dodecahedron углей, dispose.
- `shaders.ts`: 3D value noise и FBM 1–3 октавы, раздвоение/каналы, наклон, S-волна,
  независимые вспышки, Fresnel-мягкость, 3 цвета, аддитивное пламя, спиральные
  мерцающие искры, расширяющиеся дымовые клубы с подсветкой, пульсирующие 3D-угли.
- `KnottyPineFireSystem.ts`: setAnchorPoints, attachToObject, attachToInstancedTrees,
  seeded population, updateSettings, manual burn, time update, flickering PointLight,
  quality rebuild и dispose. Это emitter-owned система с четырьмя пакетами на
  экземпляр системы, не готовый редактор игрового мира.
- `codeExporter.ts`: генерация TypeScript-примера подключения, JSON настройки.
- `demoModels.ts`: костёр, сосна (включая instanced grove), ель, секвойя, сухое
  дерево, лавовый берег; геометрия и якоря демонстраций, shader поверхности лавы.
- `FireViewport.tsx`: отдельный renderer демоприложения, OrbitControls, camera
  reset/zoom, мягкие переходы камеры, PMREM/RoomEnvironment, telemetry и пересоздание демосцен.
  В software GL используется fenceSync/poll и 80 мс ожидания; показанный FPS
  ограничивается снизу 24 и сверху 60, поэтому этот счётчик не является реальным
  измерением FPS. Он не переносится: измерения ниже основаны на rAF, без подмены значений.
- `App.tsx`: три режима, шесть сцен, 12 sliders, quality, seed randomize, reset,
  ручная стадия, HUD, JSON import/export и окно кода.
- `CodeAndPresetModal.tsx`: clipboard, download, нормализация JSON. Не содержит
  постоянного каталога пользовательских пресетов, истории или кривых keyframes.
- `math.test.ts`: unit-тесты математических функций. `index.ts` — re-exports.
- README/metadata/package/index.css/main/index.html/vite/tsconfig — оболочка
  React19/Three ^0.187/Vite8, lucide-react/motion/Tailwind. Изображения и webm
  в `.aistudio/artifacts` — материалы разработки, не runtime assets библиотеки.

## Соответствие

| Возможность оригинала | До в KNOTTY PINE | Интеграция |
| --- | --- | --- |
| 3 режима / 12 параметров | Частично, свои 13 композиций | Все 3 оригинала в каталоге, все параметры в инспекторе |
| Температурная палитра | Нет | Исходная computeColorPalette и режимные поправки |
| Seeded population | Да | Локальный seed эффекта дополнительно к seed леса |
| Три качества / FBM | Частично | Исходная геометрия и шейдер, quality budgets под общий лимит |
| 2 органические оболочки, fork, S-волна, bursts, Fresnel | Своя адаптация r3 | Исходные GLSL-уравнения отдельным общим пакетом в существующем runtime |
| Icosahedron дым / шум / подсветка | Свой объёмный вариант r3 | Оригинальный шумовой профиль + существующий лёгкий вариант/ветер |
| Спиральные искры | Только баллистические | Аналитическая спираль и мерцание, общий Points пакет |
| Поверхностные угли | Свои r3 | Исходные Dodecahedron и noise/pulse heat в общем пакете |
| 4 стадии / spreadSpeed | Свой r3 | Дополнительная исходная кривая; старые данные оставляют прежнюю |
| Group / explicit anchors / InstancedMesh | Да, через proxy registry | Существующие bindings, без постоянной записи instanceMatrix |
| Dynamic PointLight | Нет на каждый очаг | Один общий ограниченный PointLight для ближайшего эффекта; без per-emitter света |
| 6 демонстрационных моделей | Реальные игровые модели | Сцены выбора из реальной игры; ассеты и лава не заменяются |
| JSON исходного FireSettings | Нет | Импорт как пользовательского пресета, экспорт исходных настроек |
| TypeScript code exporter | Старый preview имеет код | Отдельный экспорт настроек/примера для общего игрового runtime |
| Новая шкала Pause/Restart/seek/speed (в архиве автопроход/ручная стадия) | Частично | Общая шкала времени редактора, не влияет на скорость забега |
| UI React / renderer демо | Другой UI | Vanilla JS, один существующий renderer, ленивый UI |
| Избранное / recent / поиск / CRUD / clipboard paste | Нет | Новая библиотека и независимые UI prefs |
| Timeline keyframes/редактор кривых | Нет в исходнике | Не заявляется как найденная возможность |

## Подтверждённые исходные проблемы

На исходной оптической сборке воспроизведено: при 32 world-очагах быстрый Add Fire
и щелчок на том же выбранном объекте сохраняют 33-й очаг; Escape в числовом поле
закрывает редактор. Лог baseline — `studio2-reproduce.log` в рабочей среде.
В черновике 2.0 отдельно воспроизведено: изменение исходной высоты возвращало
удалённый слой coals и меняло ручной smoke.rate с 17 на 12. Исправление обновляет
только связанные с изменённым параметром поля, сохраняя независимые правки и
удалённые слои. Регрессия проверена unit- и браузерным сценарием.

Свободные world-якоря: код runtime не получает смещение дороги; их root остаётся
неподвижным, когда игровые объекты двигаются. Исправляется только связь координат
эффектов со смещением мира, без изменения скорости/препятствий.

## Границы адаптации

Исходный класс не запускается рядом с существующей системой: его вычисления и
материалы адаптируются к общим пакетам. Это ограничивает draw calls и исключает
PointLight на каждый очаг. Обе геометрии углей используют один пакет; демомодели и демошейдер лавы не заменяют игровые. React, Three r187,
генерация физического распространения пожара и keyframe curves не подключаются.
Существенные визуальные возможности, импорт и параметры доступны в адаптере;
попиксельная идентичность демоприложению не обещается.
