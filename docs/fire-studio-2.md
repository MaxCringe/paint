# Fire Studio 2.0 — работа и проверка

Полная инвентаризация исходного архива, таблица соответствия и ограничения:
[fire-studio-2-audit.md](fire-studio-2-audit.md). Исходные файлы теперь доступны,
проверены и перенесены с зафиксированными checksum в `src/systems/fire/original`.
Это продолжение редактора `6e0e53b`, без замены Three.js, React или новой системы
частиц на каждое дерево.

## Быстрый сценарий

1. Открыть «Настройки → Редактор мира» в сборке с `VITE_ENABLE_WORLD_EDITOR=true`
   или dev. Поддерживается `?worldEditor=1&seed=1337`.
2. Слева выбрать категорию или найти эффект по названию. В каталоге сохранены
   13 прежних композиций и добавлены все три режима архива: дерево, лава, тление.
3. «Предпросмотр» временно показывает анимированный эффект в этой сцене и не
   меняет сохранение. Одновременно работает только один preview, renderer общий.
4. «Добавить в сцену» включает размещение: щёлкнуть по поверхности дерева,
   деревянной переправе либо выбрать «Свободные эффекты сцены» для земли.
5. Справа выбрать слой и изменить размер/цвет. В простом режиме только основные
   параметры. «Расширенный» открывает настройки формы, источника, материалов,
   частиц и полный набор исходных параметров оригинала.
6. «Сохранить» сохраняет сцену в браузере. «Экспорт» сохраняет полный JSON.
   Изменённый образ можно сохранить в разделе «Мои пресеты».

Карточки имеют SVG-превью и настоящий анимированный preview по запросу, без
WebGLRenderer на каждую карточку. Избранное и недавние хранятся отдельно от сцены.
У пользовательского пресета есть переименование, копия, удаление с подтверждением
и отдельный экспорт. Удаление из библиотеки не удаляет размещённые эффекты.

В центре находятся манипуляторы и инструменты сцены. F — фокус, WASD/Q/E — камера,
Shift — быстрее, Ctrl/Cmd+Z и Shift+Z — история, Ctrl/Cmd+S — сохранить,
Space — пауза вне полей. Tab остаётся обычной навигацией. Escape в числовом/текстовом
поле завершает ввод, следующий Escape вне поля закрывает редактор. Панели можно
скрыть кнопками в шапке; на узких экранах они по умолчанию свёрнуты.

Шкала времени: пауза/продолжение, перезапуск, скорость ¼×–3×, время 0–120 секунд
с точным вводом. Для дерева дополнительно доступны постоянное горение, ручная
стадия и автоматическая последовательность. В расширенном режиме выбирается
исходная кривая либо прежняя художественная r3. Скорость забега не меняется.

## Данные и безопасность

Формат сцен остаётся v3. v1/v2/v3 читаются с сохранением трансформаций, слоёв,
индивидуальных bindings, групп и пользовательских пресетов. Новые поля имеют
совместимые значения по умолчанию; старые эффекты не начинают затухать.
Исходные FireSettings можно импортировать через «Импортировать эффект» или
общий импорт: они добавляются в библиотеку, не заменяют сцену и seed леса.
Локальный seed эффекта хранится независимо от seed сцены. Изменение исходного
ползунка обновляет только связанные параметры: удалённые слои и независимые ручные
правки остальных слоёв сохраняются.

Полный JSON сохраняет ручные правки слоёв и расположение. Отдельный «JSON оригинала»
содержит исходные FireSettings; их формат не описывает наши трансформации и
независимые слои. Пример подключения генерируется для настоящего JS-адаптера игры,
а не отсутствующего в игре standalone TypeScript-класса.

Перед заменой всей сцены импортом сохраняется восстановимая копия.
«Восстановить до импорта» доступно в расширенном инспекторе. Неверный импорт не
изменяет сцену. Старые пользовательские имена не перезаписываются импортом:
новому эффекту подбирается свободное имя.

«Скопировать настройки / Вставить настройки» переносит слои и настройки,
сохраняя положение целевого очага. Массовые действия показывают конкретные
деревья/переправы перед применением; другие экземпляры не меняются неявно.
Существующая кнопка «Сбросить все эффекты» перенесена одна, с прежним подтверждением.
Она очищает только данные эффектов и резервную копию импорта; рекорды, звук,
музыка и игровые настройки сохраняются.

Исправлены воспроизведённые обход лимита 32 через быстрые действия и закрытие
редактора Escape при вводе числа. Числовое редактирование больше не пересоздаёт
инспектор на каждом blur, сохраняя естественную Tab-навигацию. Свободный root
эффектов получает смещение `distance/.72` от уже существующей дистанции игры:
он следует дороге, а сохранённые локальные координаты остаются исходными.
Движение игры, скорость, препятствия и столкновения не переписывались.

## Архитектура

| Подсистема | Модули |
| --- | --- |
| Core | original/Math, OriginalPreset, ArtisticBurnCycle, EffectLayers |
| Library | EffectLayers, StudioLibrary, CompositionGallery |
| Renderer Adapter | EditableFire, OriginalRendererAdapter, original/Geometry и Shaders |
| UI | EffectPanel, WorldEditor.css |
| Inspector | EffectPanel.control, LAYER_FIELDS, ORIGINAL_FIELDS |
| Scene Tools | существующие Orbit/TransformControls, WorldEditor, CompositionLayout, proxy bindings |
| Storage | FirePreset, StudioStorage, PresetHistory |

Обычный забег и preview используют один EditableFire. Старый shader сохранён,
оригинальный — дополнительный общий instanced batch. Дым, угли и частицы также
остаются общими пакетами. Обе геометрии углей упакованы в один буфер, ненужный
диапазон пропускается; оригинальный Dodecahedron получает исходный noise/pulse.
Для ближайшего оригинального эффекта используется максимум один общий PointLight,
с ограниченной интенсивностью и без теней. Нет источника света на каждый очаг.

Общий бюджет, LOD и дальнее упрощение сохранены. Исходные quality budgets переводятся
в ограниченную плотность на локальный очаг; количество экземпляров и внешний вид
не обещаются попиксельно идентичными отдельному демоприложению. Лёгкий preview
понижает геометрию и заменяет объёмный дым картами, не перезаписывая сохранённое
качество эффекта. Оригинальные GPU-ресурсы создаются лениво, повторно используются
между превью и освобождаются при закрытии, если не нужны сохранённой сцене.

## Проверки

`npm test` включает исходные math-тесты и проверки каталога, всех границ 12
параметров при трёх качествах, миграций, бюджета, lazy allocation/dispose,
таймлайна, сохранения координат и следования дороге. Браузерные тесты проверяют
каждый зарегистрированный эффект, исходный shader в настоящем WebGL, отсутствие
второго контекста, UX/CRUD/историю/JSON/seed/сброс/повторное открытие и мобильные панели.

`effects-comparison.html` дополняет прежнее сравнение пяти форм отдельной группой
трёх оригинальных режимов: один renderer, seed 1337, фиксированные время и ракурсы.
Карточки в редакторе не запускают эту страницу или второй renderer.

В GitHub Actions добавлен отдельный job `world-editor` с обоими флагами
`VITE_ENABLE_WORLD_EDITOR=true`, `WORLD_EDITOR_TESTS=1`. Публичные smoke-тесты
сохранились и проверяют отсутствие авторского интерфейса, включая сохранённый
оригинальный эффект в обычной сборке. Результаты локальной проверки и сравнения
производительности записываются ниже после завершения проверок.

## Публикация

Интерфейс остаётся под существующим VITE_ENABLE_WORLD_EDITOR. CI-флаг не включает
редактор в Vercel production: для редакторской сборки флаг должен быть задан в её
окружении. Релиз отправляется только проверенным коммитом в main и дальше через
существующую интеграцию GitHub → Vercel; отдельные ветки, PR и ручной Cloudflare
не используются. Успешный Git push не является подтверждением Vercel deployment.

## Результаты локальной проверки

- `npm test`: 173 проверки, все успешны. Включены оригинальные math-тесты и
  регрессия сохранения независимых слоёв при изменении исходных параметров.
- Vite с флагом true и false: успешно. Публичный output не содержит WorldEditor UI.
  Существующее предупреждение о чанке ForestFireStudio >500 КБ остаётся.
- Полный opt-in browser suite: 12 успешных сценариев, публичный smoke-сценарий
  ожидаемо пропущен. После калибровки дыма/углей дополнительно пройдены сравнение
  четырёх групп в трёх ракурсах и компиляция всех 16 эффектов в одном контексте.
- После исправления независимых слоёв отдельно повторён оригинальный UI-сценарий
  с вводом, clipboard, CRUD, JSON, восстановлением, timeline и reopen — успешно.
- Публичная сборка: 6 успешных browser-сценариев, авторские сценарии ожидаемо
  пропущены. Проверены обычный/длинный забег, меню/настройки и сохранённые исходные
  эффекты без авторского интерфейса. JS/WebGL ошибок в этих проверках нет.
- Реальная видеокарта, телефон и удалённая Vercel-сборка в среде не проверены.

### Производительность

`scripts/benchmark-authored-effects.mjs` запускает Chromium/SwiftShader в 1280×720,
seed 1337, бюджет 1024, три источника, без редактора (игровая сцена до старта).
Первые 20 кадров прогревают шейдеры, следующие 20 измеряются. Прогоны выполнялись
последовательно, без параллельной WebGL-работы. В benchmark Math.random заменяется
фиксированным PRNG только внутри тестового браузера, игровой код не меняется.

| Сборка / композиция | Медиана, мс | p95, мс | Draw calls |
| --- | ---: | ---: | ---: |
| 6e0e53b / прежний inferno | 916.6 | 1683.3 | 99 |
| 2.0 / тот же inferno | 866.7 | 1533.3 | 99 |
| 2.0 / оригинальный tree, high | 933.2 | 1866.5 | 99 |

Для одинакового старого пресета медиана не ухудшилась (примерно −5%). Оригинальный
высококачественный shader — другая композиция и стоит дороже; его строка не является
прямым before/after-сравнением. Бюджет и число общих пакетов остаются ограниченными.
Абсолютные значения программного GPU не следует выдавать за FPS на настоящем
железе; p95 на этой среде нестабилен. Исходный демосчётчик с минимумом 24 FPS
для сравнения не использовался.
