# Три внешние FBX-анимации для Фионы — первый тест

Файлы загружены пользователем в `public/models/fiona/animations/fbx/`:
- `Fast Run.fbx` → бег Фионы (режим по умолчанию, переключение между FBX и двумя прежними Python-бегами).
- `Running Jump.fbx` → обычный прыжок (двойной прыжок пока Python).
- `Flying.fbx` → полёт на метле и полёт во время ульты, только для тестового персонажа.

В `src/player/FionaImportedFBX.js` загрузчик читает бинарные FBX и использует только дорожки кватернионов костей. Кости сопоставляются по очищенным именам, вращения пересчитываются относительно исходной позы каждого скелета, чтобы не переносить ошибочные смещения. Root-motion/position/scale из чужого файла не затрагивают физику или масштаб Фионы. Если костей слишком мало, импорт считается несовместимым: ошибка видна в DEV-панели, а Python остаётся запасным вариантом.

`tests/fiona-imported-fbx.test.js` проверяет логику сопоставления и защиту от несовместимого скелета; `tests/browser/game-smoke.spec.js` проверяет реальный запуск всех трёх новых файлов в Chromium.

Это **первый тест** импортированных анимаций. Физические столкновения, скорость, высота прыжка, метла, ульта и обычная Фиона не меняются. Художественное качество, выравнивание ног и посадка на метле требуют визуальной проверки.
