# Тест внешних FBX-анимаций Фионы

В работе остались два FBX-файла, загруженных пользователем:
- `Fast Run.fbx` — бег с переключением на два прежних Python-варианта.
- `Running Jump.fbx` — первый прыжок. Двойной прыжок пока Python.

`Flying.fbx` удалён из актуального `main` по просьбе пользователя. Он **не загружается и не проигрывается**. Для полёта на метле и во время ульты временно остаются существующие Python-анимации; игровая высота, скорость и столкновения не изменялись. Файл при необходимости можно восстановить из истории Git.

**Сбор душ не вызывает анимацию персонажа** — только звук, вибрацию, визуальные эффекты, счётчик и накопление ульты. В `src/game.js` нет вызова `trigger('soulPickup')`, а контроллер `src/player/FionaTest.js` дополнительно игнорирует такое событие. Нажатие «Сбор души» в DEV-панели объясняет отсутствие анимации и возвращает базовый бег (или текущее базовое движение).

`src/player/FionaImportedFBX.js` загружает только разрешённые файлы; кости сопоставляются по именам, передаются только их вращения, без root-motion/масштаба. При несовместимости импорт пропускается и используется Python-клип.

Проверки: `tests/fiona-imported-fbx.test.js` и реальный Chromium WebGL из `tests/browser/game-smoke.spec.js`.

Обычная Фиона, физика бега/полёта, механика души и сохранённые рекорды не менялись.

## Новые реакции и смерть от рыбы (1 ноября)

Три добавленных пользователем FBX:
- `Edge Slip.fbx` → `slipFBX`: скольжение при наступании на лужу, **без смерти**. Анимация одноразовая; блокировка управления по-прежнему длится 0,9 секунды.
- `Standing React Death Right.fbx` → `deathFBX`: общая смерть (кроме рыбы).
- `Stumble Backwards.fbx` → `fishDeathFBX`: **самостоятельная смертельная анимация именно при столкновении с рыбой**. Не запускается `Standing React Death` после этого клипа.

В DEV-забеге экран поражения появляется после завершения соответствующей анимации смерти. Обычный режим и физика столкновений не менялись. Для отдельного просмотра смерти от рыбы в DEV-панели добавлена кнопка. Предыдущие 23 Python-слота остались на своих местах.
